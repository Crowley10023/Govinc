External API Description

Authentication for all endpoints:

X-API-Key: <your generated api key>

1) List available security catalogs

GET /public-api/v1/catalogs

2) List assessments for one security catalog

GET /public-api/v1/catalogs/{catalogId}/assessments

3) Get all control answers for one assessment

GET /public-api/v1/assessments/{assessmentId}/answers

Example curl call:

curl -H "X-API-Key: YOUR_KEY" http://localhost:8080/public-api/v1/catalogs
