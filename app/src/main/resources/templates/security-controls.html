📋 CSV Format Requirements

Please ensure your CSV file follows the exact format specified below:

Required Columns (in this exact order):
  • name
  • detail
  • reference
  • domain
📝 Example CSV Format:
name,detail,reference,domain "Access Control Policy","Implement comprehensive access control policies","AC-1","Access Control" "Account Management","Manage user accounts and access rights","AC-2","Access Control" "Network Segmentation","Implement proper network segmentation","SC-7","System and Communications Protection"
💡 Important Notes:
  • The first row must contain the column headers exactly as shown
  • Use double quotes around values that contain commas
  • The domain column should match existing domain names or new ones will be created
  • Empty fields are allowed but not recommended
  • UTF-8 encoding is recommended for special characters
