📋 CSV Format Requirements

Please ensure your CSV file follows the exact format specified below:

Required Columns (in this exact order):
  • name
  • detail
  • reference
  • domain
📝 Example CSV Format (supports newlines in quoted fields):
name,detail,reference,domain "Access Control Policy","Implement comprehensive access control policies","AC-1","Access Control" "Account Management","Manage user accounts and access rights","AC-2","Access Control" "Network Segmentation","Implement proper network segmentation","SC-7","Network"
💡 Important Notes:
  • The first row must contain the column headers exactly as shown
  • Use double quotes around values that contain commas or newlines
  • You CAN include newlines (line breaks) within quoted fields
  • Escape quotes inside quoted fields by doubling them: "" becomes one quote
  • The domain column should match existing domain names or new ones will be created
  • Empty fields are allowed but not recommended
  • UTF-8 encoding is recommended for special characters
