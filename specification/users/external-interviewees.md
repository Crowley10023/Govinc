# External interviewees

- After an assessment email is successfully sent, record external recipients as interviewees of that assessment. Do not create interviewees for failed sends or duplicate an existing email address.
- Maintain a shared external interviewee directory. The configuration users screen separates internal and external users into tabs; external entries can be viewed and deleted, not edited or created there.
- When the external URL is selected in the assessment email dialog, show the external interviewees already associated with that assessment for recipient selection.
- External interviewees are not login accounts and must not gain internal access.
