# Qualified feedback

- A security catalog can enable qualified feedback. Existing catalogs default to disabled.
- When enabled, each assessment control can have one of three ratings: more detail needed, revision needed, or accepted. An unset rating remains possible.
- Information security managers can set the rating; assessors and assessor delegates can see it but cannot change it. Enforce this on the server as well as in the interface.
- All assessment control views, including external assessment views, display the rating and offer a filter when the catalog enables the feature. Disabled catalogs do not expose the control or filter.
- Ratings are specific to an assessment and control and persist independently of maturity answers and comments.
