# External review notification

- When an external assessment is successfully submitted as ready for review, create an informational governance task assigned to the assessment creator.
- The task identifies the assessment and states that it is ready for review. Failed or repeated submissions must not create additional tasks.
- The assessment is the task's related item, and the task's View button opens the assessment.
- Change the assessment status and create its task in the same transaction. Historical assessments without a creator cannot receive an assigned task.
